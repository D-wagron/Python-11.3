# Python Terminal Games

A collection of games that run in the terminal

## How to install:

### Option 1: (Linux executable)
    
[Donload the Linux Binary from here](https://github.com/D-wagron/Python-11.3/releases/tag/v1.1.0)

For windows:
1. Download menu.py from [here](https://github.com/D-wagron/Python-11.3)

2. Open up a code editor and run the file through there, or

Or

### Option 2: Run from Source (Windows, macOS, or Linux)
**Prerequisites:** Python 3 installed on your system.

1. Download `menu.py` from the [repository](https://github.com/D-wagron/Python-11.3).
2. Open your terminal or command prompt and navigate to the folder containing `menu.py`
3. Run the script using the command for your operating system:
   * **Windows:** `python menu.py`
   * **Linux / macOS:** `python3 menu.py`

*Alternativey you can open 'menu.py' in a code editor like VS Code and click the run button

*(Optional, but appreciated): enjoy


 Each of these games give the user a score, and tracks these scores in the highscore section of the menu.

 From the first page of each game menu, you have the option to return to the menu.

 All games are finished
