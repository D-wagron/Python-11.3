# Python Terminal Games


Games include: 

 - (Russian) Roulette

 - Number guessing game

 - Choose your own adventure


 Each of these games give the user a score, and tracks these scores in the highscore section of the menu.

 From the first page of each game menu, you have the option to return to the menu.

 All gamea are finished
